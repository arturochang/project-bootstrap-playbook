# Prompt Migrations

Migration guides describe changes to the artifacts and working contract produced
by the prompt. They do not perform automatic edits.

Use the guide matching the version recorded in the target project's
`docs/setup-provenance.md` or earlier setup notes. Review the proposed diff and
preserve project-specific decisions; never regenerate the whole documentation
set over a mature repository.

Available guides:

- [`v1-to-v2.md`](v1-to-v2.md) — adopt operating modes, delivery targets,
  provenance, capability-first provider selection, and deployment/operations
  evidence.
