# Changelog

All notable changes to the project setup prompt are recorded here.

## 2.1.0 - 2026-09-20

- Added the first dated Cloudflare provider profile.
- Added migration guidance for adopting version 2 from a version 1 project.
- Added minimal and production-oriented Cloudflare project-input examples.

## 2.0.0 - 2026-09-20

- Made the prompt coding-agent and cloud-provider neutral.
- Added new-project, existing-project, and assessment operating modes.
- Added explicit design, local, preview, and production delivery targets.
- Added setup provenance, security, deployment, operations, and handoff outputs.
- Added capability-first provider selection with Cloudflare and AWS guidance.
- Added cost failure modeling, safer CI, release evidence, rollback, and
  production-probe constraints.
- Added complete implementation-packet requirements for delegation to smaller
  models.
- Added safe repeated-setup behavior and prompt versioning.

## 1.0.0

- Initial reusable project setup prompt, developed from lessons learned while
  building and deploying Portal.
